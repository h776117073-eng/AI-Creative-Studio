# AL-DIDAH Anime Production Pipeline

Open the Colab notebook:
https://colab.research.google.com/github/h776117073-eng/AI-Creative-Studio/blob/main/notebooks/AL_DIDAH_Anime_Production.ipynb

## Inputs
- Source folder: https://drive.google.com/drive/folders/1D5EaANB1ycUQ5SHJcjb6PjdS6UE372aV
- Character image IDs are configured in the notebook.
- If Drive items are not publicly accessible, set them to **Anyone with the link → Viewer**.

## Outputs
The notebook writes analysis artifacts and a ZIP to a GitHub Release. Add a Colab Secret named GH_TOKEN with a fine-grained PAT scoped to this repository with Contents read/write.

## Scope
Analysis, source preservation, scene/motion extraction, transparent character reference plates, QA sheets, and production handoff. It does not claim to generate a finished broadcast-quality anime episode or a fully rigged 3D model.
